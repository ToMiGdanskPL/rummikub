Jak opublikować na GitHub Pages?

Darmowy hosting Twojej aplikacji w 3 proste kroki!

1

Utwórz repozytorium na GitHubie

Zaloguj się na GitHub.com, kliknij New Repository, nazwij je np. rummikub-timer i ustaw jako Publiczne.

2

Prześlij plik HTML

Dodaj plik z kodem tej strony. Pamiętaj, aby nazwać go dokładnie: index.html i zatwierdź (Commit).

3

Włącz GitHub Pages

Przejdź do Settings -> Pages w menu repozytorium. W sekcji Build and deployment / Branch wybierz gałąź main (lub master) i kliknij Save.

Gotowe! Po minucie Twoja strona będzie dostępna pod adresem:
